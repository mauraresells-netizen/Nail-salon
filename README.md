# Nail Salon

A single-page luxury website for **Nail Salon** — Glasgow's boutique nail studio. Feminine, romantic and quietly luxurious, built as a single self-contained `index.html` (HTML, CSS and vanilla JavaScript — zero frameworks or libraries).

## Features

- **Cinematic splash entry** with a dissolve animation into the main site
- **Cherry-blossom petals** drifting over the hero, with occasional gold-dusted petals
- **Scroll-reveal animations** throughout via Intersection Observer
- **Editorial sections**: hero, services menu, about, signature look (parallax), gallery with lightbox, testimonials carousel, booking form, FAQ accordion, find-us, Instagram strip
- **Hand-drawn SVG nail illustrations** (polish bottles, french tips, nail art, swatches) in `img/`
- **Performance-tuned**: a single rAF-throttled scroll handler with cached layout metrics and GPU-composited transforms
- Fully **responsive** with a mobile slide-in menu

## Palette & type

Soft blush rose, deep rose, champagne gold, warm white and near-black. Cormorant Garamond (serif) paired with Raleway (sans).

## Usage

Open `index.html` in any modern browser. To use real photography, replace the `background-image` swap points (the gallery, about, signature-look and Instagram boxes) and the splash background.
